# Balance Hot Yoga (Одесса) — Официальный сайт студии

Авторский веб-сайт для единственной специализированной студии горячей йоги в Одессе — **Balance Hot Yoga** (@yoga_balance_odessa).

---

## 1. Концепция и визуальный стиль

Проект выполнен в концепции **Immersive Yoga**:
- **Атмосфера тепла и дыхания:** глубокие приглушенные оттенки оливкового (`#293A30`), терракоты (`#B87557`), янтаря (`#D4793A`), темного графита (`#222923`) и теплого молочного фона (`#F5F2E9`).
- **Иммерсивный элемент:** интерактивный холст `AtmosphericCanvas`, создающий органические волны тепла и ощущение спокойного дыхания (с полным учетом системной настройки `prefers-reduced-motion`).
- **Типографика:** сочетание акцентного антиквенного шрифта **Cormorant Garamond** с засечками и современного функционального гротеска **Manrope** с поддержкой кириллицы.
- **Tone of voice:** честный, глубокий язык реального бренда («Жарко. Влажно. Местами очень непросто. Но какое же после этого состояние…»).

---

## 2. Реальные данные и исследование бренда

Все материалы основаны на исследовании официального профиля [Instagram @yoga_balance_odessa](https://www.instagram.com/yoga_balance_odessa/):
- **Основательница студии:** Мария Миронова ([@m8mironova](https://www.instagram.com/m8mironova/)).
- **Специализация:** Горячая йога (Hot Yoga) в оборудованном зале с температурой 38–40°C и контролем влажности.
- **Статус студии:** Новое пространство (открыто осенью 2026 г.).
- **Канал связи и записи:** Instagram Direct.
- **Реестр ассетов:** подробно зафиксирован в файле `docs/instagram-assets.md`.

---

## 3. Технологический стек

- **Фреймворк:** Next.js 16 (App Router, React 19, Server & Client Components).
- **Язык:** TypeScript со строгой типизацией.
- **Стилизация:** Tailwind CSS 4 с централизованной системой токенов и шрифтов.
- **Иконки:** Lucide React.
- **Анимации:** Нативный Canvas API, CSS Keyframes (`fadeInUp`, `breathe`).
- **SEO & Локализация:**
  - Двуязычность (`/ru` и `/uk`) с сохранением пути при переключении.
  - Семантическая разметка HTML5.
  - Метатеги Open Graph, canonical и hreflang для всех страниц.
  - Микроразметка Schema.org JSON-LD (`SportsActivityLocation`).
  - Автоматическая генерация `sitemap.xml` и `robots.txt`.

## 5. Быстрый запуск

### Установка зависимостей:
\`\`\`bash
npm install
\`\`\`

### Запуск сервера разработки:
\`\`\`bash
npm run dev
\`\`\`
Сайт доступен по адресу: [http://localhost:3000](http://localhost:3000)

### Production-сборка:
\`\`\`bash
npm run build
npm run start
\`\`\`
